# ADR-003: Closed-form answers are written by code; the LLM only narrates evidence

**Status:** Accepted

## Context

Rankings, learn checks, move info, type charts, damage and survival numbers are
exact facts. An LLM paraphrasing them can drop, reorder or invent names and numbers.

## Decision

Tools marked `closed_form` have a renderer (`render.py`); when every step of a plan is
closed-form, code writes the answer with no LLM call. Otherwise the LLM answers only
from the numbered evidence chunks, cites `[n]`, and abstains when the data can't
answer.

## Consequences

- Fast-path closed-form questions cost 0 LLM calls.
- A tool may be marked `closed_form` only if a renderer is added with it.
- How it works: [ask-agent.md §4](../architecture/ask-agent.md#4-answering-runner_answer_body).
