# ADR-007: The team summary is written in the background; grades stay deterministic

**Status:** Accepted · grade location amended by [ADR-009](ADR-009.md) (2026-10-09)

## Context

An LLM call on page load would make `/teams/{id}` slow and fragile under rate limits,
and LLM-assigned grades would change between views of the same team.

## Decision

`GET /summary` never calls the LLM. The summary is stored with a roster fingerprint
and rewritten in the background (debounced, at most 2 in flight) only when slots
change. Team grades are computed by `frontend/lib/teamEval.ts`; the LLM only phrases
facts that rules decided.

## Consequences

- Opening a team page costs 0 LLM calls; a stale summary is acceptable briefly.
- Since 2026-10-09 the grades are computed by `backend/app/services/team_rating.py`
  and returned with the team analysis ([ADR-009](ADR-009.md)); they are still rules,
  never the LLM.
- Details: [team-coach.md](../architecture/team-coach.md#the-ai-summary).
