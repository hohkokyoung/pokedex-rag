# ADR-004: Writes are gated in code, not in prompts

**Status:** Accepted

## Context

The team coach can change a team. A prompt instruction ("only add when asked") can be
ignored or misread by the model; "should I add Garchomp?" must never write.

## Decision

All tools are read-only except `add_member`, and it writes only when
`is_imperative_add(question)` agrees. Every other change (Apply, Add, Replace, Revert)
is a user click on a card the coach proposes. Coach and calc answers are never cached.

## Consequences

- A model mistake can at worst propose a change, not make one.
- A real add emits `team_updated` and the reply offers Undo.
- Details: [team-coach.md](../architecture/team-coach.md#the-coach).
