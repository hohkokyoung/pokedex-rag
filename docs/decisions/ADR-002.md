# ADR-002: One tool-planning agent; the LLM picks tools, no routes

**Status:** Accepted

## Context

Ask, the team coach and the calc coach each need to answer free-form questions over
the same data. Hard-coded intents/routes broke on phrasings nobody anticipated and
had to be extended per question shape.

## Decision

One agent (`backend/app/agent/`) runs all three surfaces. A question becomes a plan of
typed tool calls; the LLM planner chooses tools and fills their arguments. A keyword
planner emits the same plan format and runs first, so a confident keyword plan skips
the LLM entirely. New capabilities are new read-only tools, never new routes. Tools
never see the question text — only validated arguments.

## Consequences

- Keyword and LLM plans are interchangeable and reproducible from their arguments.
- Strict tool schemas mean the LLM can only express what a tool accepts; anything it
  can't apply is reported as `unhandled` so the answer can say so.
- Every tool and argument costs planning-prompt space ([ADR-008](ADR-008.md)).
