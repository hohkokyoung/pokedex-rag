# ADR-006: One damage formula in TypeScript, ported to Python and fixture-checked

**Status:** Accepted

## Context

The calculator runs in the browser for instant feedback; the calc coach needs the same
numbers server-side for `damage_calc` and `survive_threshold`. Two independent
implementations would drift.

## Decision

`frontend/lib/damageCalc.ts` is the reference. `backend/app/services/damage_calc.py`
is a port. `make damage-fixtures` generates reference cases from the TS, and the
Python test suite checks the port against every one. Team duels (`services/battle.py`)
are a separate engine on purpose.

## Consequences

- Any formula change is: edit TS → port → `make damage-fixtures` → `make test`.
- Client-sent stats are never trusted; the backend re-resolves them from the DB.
- Details: [damage-calc.md](../architecture/damage-calc.md).
