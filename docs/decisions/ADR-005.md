# ADR-005: Every LLM feature works keyless, on a fixed call budget

**Status:** Accepted

## Context

This environment runs Groq's free tier (`gpt-oss-120b`) with tight token-per-minute
limits; the app must also run with no key at all.

## Decision

- Every LLM feature has a fallback: keyword plan, code-rendered or extractive answer.
- A 429, timeout or bad response falls back immediately — never a retry loop.
- At most 3 calls per Ask question (plan, re-plan, answer); fast-path closed-form
  questions use 0. The planning prompt is capped at `PROMPT_BUDGET` per scope.
- Calls stay Groq-friendly; Anthropic Claude is preferred when keyed.

## Consequences

- Quality degrades gracefully instead of failing.
- Each fallback is recorded in the plan trace, so it's visible after the fact.
- Budget table: [ask-agent.md §5](../architecture/ask-agent.md#5-budget-and-caching).
