# ADR-008: Team and calc scopes get a smaller tool set to fit the planning prompt

**Status:** Accepted

## Context

The planning prompt is capped at `PROMPT_BUDGET` (11,000 chars) per scope. The team
scope adds coach tools and context, which left it nearly full.

## Decision

Lore search (`semantic_search`), look-alikes (`similar_to`), profile picks
(`user_profile`) and `encounters` are offered only in the Ask scope. The budget was
raised once, with the user's agreement; a test enforces it.

## Consequences

- Any new tool, argument or planner rule needs a matching trim, or the budget test
  fails.
- Coaches can't answer lore or where-to-catch questions; Ask can.
- Details: [ask-agent-planners.md](../architecture/ask-agent-planners.md#llm-planner-llm_plannerpy).
